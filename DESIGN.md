# SIBC interface

The site uses a bright white reading surface, bamboo green (`#214f40`) and
restrained saffron links/focus (`#a55319`). Dark green grounds the welcome and
footer without obscuring navigation. Georgia display headings and system
body fonts keep the interface independent of third-party font requests;
Sinhala/Khmer use available native-script fallbacks and expanded line height.

The home page is a photographic welcome, not an event-promotion dashboard.
The full temple name and inclusive mission sit beside an actual temple image,
followed by ruled directions/calendar/giving links and source-based community
copy. Source-photo crops and religious-image treatment remain review items.

Core pages share one responsive shell. At narrow widths the layout becomes one
column, the keyboard-operable menu expands in-flow, and donation selections
retain native radio/checkbox semantics. Source archives have prominent historical
context; draft language status and disabled/test-only payment states are visible.
No active event or campaign is inferred from old material.

Accessibility target is WCAG 2.2 AA: semantic landmarks, one page heading,
skip link, visible focus, sufficient text contrast, reflow, descriptive image
alternatives and reduced-motion behavior. Third-party calendars load only after
an explicit action. Do not remove review/no-live-payment notices before approval.
